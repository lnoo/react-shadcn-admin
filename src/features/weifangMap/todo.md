# 3D 地球（卫星影像）→ 飞入潍坊 2.5D 碳排放地图
在 ***src/features/weifangMap*** 中实现

## 一、项目目标
实现沉浸式数据可视化：
1. 初始为可交互 3D 地球，使用卫星影像 `world.png` 作为球体贴图。
2. 相机平滑飞入山东省潍坊市。
3. 飞入结束后平滑过渡到 2.5D 本地地图。
4. 2.5D 地图使用卫星影像 `weifang.png` 作为底图，叠加 `weifang.geojson` 区县边界与挤出效果。
5. 每个区县显示聚合碳排放 mock 数据（颜色映射 + 数值标注）。
6. 点击区县后高亮、镜头二次聚焦，并展示该区县下公司/单位碳排放列表（mock）。
7. 支持返回潍坊整体视图与返回全球地球视角。

所有业务数据均为 mock，后续可替换为真实接口。

## 二、资源说明（重要）
资源来自 https://github.com/lnoo/sat-hunter（卫星瓦片拼接工具）：
- `./world.png`：全球卫星拼接图（低 Zoom 级别，建议 Zoom 1~3）
- `./weifang.png`：潍坊区域卫星拼接图
- `./weifang.geojson`：潍坊市区县边界 GeoJSON

注意：
- 这些是真实卫星影像，不是矢量政治地图。
- `world.png` 用于球体时，需确认其大致投影（Leaflet 瓦片通常为 Web Mercator，低 Zoom 全球图可近似当作等距圆柱处理，必要时做 UV 校正）。
- `weifang.png` 必须与 `weifang.geojson` 的经纬度范围对齐。实现时应预留「图片地理范围配置」（西、南、东、北四个角的经纬度），方便微调对齐。

## 三、技术栈
- Three.js
- 动画：GSAP
- 投影：d3-geo（处理 GeoJSON → 平面坐标）
- 控制：OrbitControls
- 文字标注：CSS2DRenderer

## 四、功能详细需求

### 4.1 初始 3D 地球
- SphereGeometry 贴 `world.png`（卫星真实影像风格）。
- 添加简单光照、可选大气层外发光、星空背景。
- 支持拖拽旋转、滚轮缩放（限制距离）。
- 页面加载后延迟 1.5 秒自动触发飞入，或提供「进入潍坊」按钮。

### 4.2 飞入动画
- 目标：潍坊市中心（约 119.15°E, 36.71°N）。
- 时长 2 秒左右，easeInOutCubic。
- 飞入过程锁定交互。
- 接近结束时开始准备 2.5D 地图淡入。

### 4.3 过渡到 2.5D
推荐方案：
- 球体淡出 + 缩小。
- 同时 2.5D 平面地图（带轻微透视）从中心放大淡入。
- 过渡时长约 0.8 秒，与飞入尾部重叠，做到视觉连贯。
- 过渡完成后可销毁球体资源。

### 4.4 2.5D 本地地图
- 底图：PlaneGeometry 贴 `weifang.png`（卫星影像）。
- 相机：透视 + 轻微俯视（45°~60°），OrbitControls 限制极角。
- 区县：
  - 解析 `weifang.geojson`。
  - 使用 d3-geo 投影，并与 `weifang.png` 的地理范围严格对齐（通过配置图片四角经纬度实现）。
  - ExtrudeGeometry 挤出，高度可简单映射碳排放或统一高度。
  - 填充色按碳排放量映射（绿→黄→红）。
  - 区县中心显示名称 + 聚合数值。
- 提供颜色图例。

### 4.5 点击交互
- 点击区县 → 高亮（描边发光 + 亮度提升 + 可选高度抬升）→ 镜头飞向该区县 → 显示公司列表面板。
- 公司 mock 字段：名称、碳排放量（吨）、行业、同比等。
- 点击空白或返回按钮：取消高亮，回到潍坊整体视图。
- 提供「返回地球」按钮，反向过渡回 3D 球体。

### 4.6 Mock 数据
- 区县聚合碳排放：随机合理数值（如 5000~80000 吨）。
- 每个区县随机 5~15 家公司数据。
- 数据独立可替换。

## 五、视觉规范
- 暗色科技风大屏。
- 卫星底图保持真实感，高亮用科技青/蓝色描边 + 发光。
- 文字清晰，带背景板或描边。
- 所有动画平滑，目标 60fps。

## 六、关键实现提示
1. `weifang.png` 与 GeoJSON 对齐是核心难点，必须做成可配置的地理范围（bounds）。
2. 全球卫星图贴球体时，注意接缝与极点拉伸，必要时对 texture 做偏移或使用更标准的 equirectangular 图作为备选。
3. 飞入 + 过渡动画建议用 GSAP timeline 统一管理，方便控制时序。
